# Стрес тестове на компоненти

Страници, с които се проверява как се държат отделни компоненти при неудобни
ширини и при повече данни, отколкото обикновено получават.

Папката започва с `_`, затова Astro не създава маршрути за нея — нито при
разработка, нито в билда. Така тестовете си остават във версията, но никога не
се озовават на живия сайт.

## Как да ги пуснеш

Преименувай папката временно и стартирай сървъра:

```sh
mv src/pages/_break src/pages/break
npm run dev
```

Страниците са на `/break/contact-form/` и `/break/stats/`.

**Върни името, преди да комитнеш:**

```sh
mv src/pages/break src/pages/_break
```

Ако това се забрави, страниците тръгват към продукция при следващия деплой.

## Какво има вътре

- `contact-form.astro` — формата за контакт в контейнери от 320, 520 и 960 px
- `stats.astro` — блокът с числа при различен брой елементи
